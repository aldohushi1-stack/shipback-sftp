While this app is running, anything that can write a file can trigger a run — an AI agent with no shell, a script, you. Drop a request into the queue folder; the result and log land beside it.

queue\homepage.request.json
{ "action": "deploy", "site": "mysite",
  "localDir": "C:\\work\\mysite", "dryRun": false }

→ queue\homepage.result.json  +  homepage.log.txt
